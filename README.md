# 旅規ナビ 0.10 — 軽量版

公開された旅客営業規則を、条文検索と原文に照合した基本案内から調べるWebアプリです。

## 利用方法

https://motofukuoka-a11y.github.io/ryoki-navi/

登録・ログインはありません。AIモデルのダウンロード、生成AIの端末実行、追加学習、外部AI APIの呼び出しを取り除きました。起動準備ボタンはなく、質問を入力して送信ボタンを押すと検索します。Enterは改行で、送信しません。

従来の重さは、大きな学習済みモデルで文章を生成する推論処理に由来します。利用中にディープラーニングの追加学習を続けていたわけではありません。この版はその推論処理も使いません。

検索データは最初の質問時に読み込み、Web Workerで画面とは別に処理します。通常のWebコードと公開資料のデータであり、ニューラルネットワークの重みは含みません。旧版で取得したモデルのブラウザキャッシュは自動削除しませんが、この版では読み込まず、実行しません。

## 回答できる範囲

途中下車・有効期間・未使用普通乗車券の払戻・小動物の持込・第190条の券面様式について、照合済みの基本案内を表示します。条番号を指定した質問では、指定条文の収録原文を優先します。それ以外は関連資料の検索結果を表示します。自由な文章生成や、未知の条件に対する新しい解釈は行いません。

収録資料は2026年11月19日確認のJR北海道の公開資料35件・760区分です。公開資料には省略と未統合の改正があります。JR東日本・ICカード・企画乗車券の専用規則は未収録です。個別の取扱いは出典の原文と改正公告を確認してください。

## データと料金

会話はページ内のメモリで保持し、再読み込みで消えます。必要な回答は利用者が保存ボタンから書き出せます。質問は外部AIへ送信しません。サーバーの会話履歴や個人の訂正メモには接続しません。

質問ごとのAI API料金はありません。アプリ側に日次の質問回数制限はありません。GitHub Pages等の公開先の配信条件・通信量・レート制限は適用され、無制限のサーバー稼働を保証するものではありません。Cloudflare等の追加アカウントは不要です。

## 修正・更新の方法

1. 検索語を増やす場合は`lib/rail.ts`の同義語表を修正します。
2. 基本案内の文章は`lib/reference.ts`で修正します。元の条文のSHA-256と一致した場合だけ、対応する案内を有効にします。原文が変わった場合は内容を再確認し、正しいハッシュを設定するまで停止します。
3. 条文指定や案内の振り分けは`lib/light-answer.ts`、表示は`components/rail-chat.tsx`で修正します。
4. 収録資料は`data/corpus.json`と`public/documents/`にあります。文書一覧のメタデータ`data/catalog.json`も同時に更新します。
5. Node.js 22.13以上で`npm ci`、`npm run typecheck`、`npm run build`を実行します。
6. `dist/`を公開します。このリポジトリの`site-*.zip`と`site.sha256`を更新するとGitHub Actionsが検証・公開します。

`source-01.zip`から`source-03.zip`は編集可能な最新版ソースです。全てを新しい空フォルダーへ展開してください。`node_modules`・ビルド結果・認証情報・個人の履歴は含めません。

個別の不具合は、再現する質問・選択会社・利用日・期待する根拠条文を確認し、該当する検索語・案内文・判定処理を修正して再公開する運用です。会話から自動学習する機能はありません。
