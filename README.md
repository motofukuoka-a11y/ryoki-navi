# 旅規ナビ 0.16 — 意味と条件を照合する共通回答

公開: https://ryoki-navi-trial.motofukuoka-ryoki.workers.dev/

JR北海道の公開資料を検索し、出典を付けて回答するWebアプリです。利用者の登録・ログイン、端末へのAIモデル保存、WebGPUは不要です。Enterは改行し、送信ボタンで送信します。

## 履歴と回答の再利用

完了した質問と回答はCloudflare D1に保存します。ブラウザにはランダムな識別用Cookieだけを保持します。CookieはHttpOnly・Secure・SameSite=Strict・ホスト限定で、サーバーにはそのハッシュを保存します。同じブラウザでは再読み込み後も履歴を復元でき、他の利用者に一覧を公開しません。Cookie削除、プライベートブラウジングの終了、別端末・別ブラウザでは同じ履歴を復元できません。

直近50チャット・1チャット30回答ずつを読み込み、「以前のチャット／回答を表示」で古い履歴も読み出せます。表示件数を超えたために自動削除はしません。削除操作は個人履歴の質問・回答を削除し、その個人履歴から再利用しません。共通回答として保存済みの回答は、個人履歴の削除後も共通で利用します。通信中止・失敗など、回答が完了しなかった質問は保存しません。保存先の上限・接続障害時は「履歴未保存」とエラーを表示し、手動のファイル書き出しを利用できます。

定型質問に加え、個別に生成したAI回答も利用者間で再利用します。画面の「単独の規則質問を共通回答として利用」は既定でオンです。会話の前提がない単独のJR北海道の規則質問で、共有を有効にした場合に共通回答を保存します。質問文・利用日・対象会社・AI設定・資料と回答処理の版が完全一致すれば、別のCookie・端末・操作場所からでも、AIを再実行せず共通回答を返します。Cookieは自分の履歴一覧の識別にだけ使い、共通回答の照合キーには含めません。

完全一致は質問と条件のハッシュを索引で照合し、AIを呼び出さず返します。完全一致しなくても、意味検索で候補を探し、質問の目的と明示された条件が同じ場合に共通回答を再利用します。人数の数字だけでなく対象との対応、年齢、券種、使用前後、経路の向き、重さ・大きさと単位・上限条件、列車・座席、否定などを確認します。「大人1人と4歳児3人」と「大人3人と4歳児1人」は別条件です。確認できない条件、相違、曖昧さがあれば再利用せず通常のAI回答へ進みます。

同じ会社・利用日・資料と処理の版の範囲で、同分野の直近80件と全分野の直近80件を索引から取得します。明示条件の差で候補を除外してからBGE-M3で検索し、類似度0.76以上の上位2件までをGemma 4で照合します。類似度だけで同一とは判断しません。元の質問全文と条件を比較し、目的を含む10観点の確認、相違・不確実性なし、構造化した判定の検証がそろった場合に限り再利用します。照合は合計8秒で打ち切り、通常のAI処理へ進みます。遅れて完了した判定から別名を作りません。回答を読み取るAIの設定は変更していません。

初回の照合に通った言い換えは、元の回答を指す別名として保存します。同じ言い換えが次に届けば、意味検索やAIによる再照合を省略できます。別名を新しい意味照合の基準にはせず、段階的に条件が緩くなる連鎖を防ぎます。再利用時には収録原文との対応を確認します。確認済み基本案内は、現在の資料・規則から同じ案内を再構成できる場合だけ対象とし、原文表示だけの回答は意味照合の基準にしません。表示には元の生成日時と「意味・条件を照合した共通回答」または「利用者共通の保存済み回答」を付け、言い換えでの再利用時は「意味・条件の照合結果」を確認できます。出典検証や意味照合は結論の完全な正確性を保証しません。

共通領域には、共有した回答に加え、意味照合のための質問文・検索ベクトル・抽出条件を保存します。Cookie、利用者の識別ハッシュ、チャットID、元の回答ID、会話履歴、私的な質問比較メモは含めません。個人情報は入力せず、共通利用が適さない質問ではチェックを外してください。メールアドレス・電話番号・社員番号などを検出した質問、会話の続き、共通利用がオフの質問は共通領域への読み書きを行いません。自動検出があらゆる個人情報を見つける保証はありません。

旧版の個人履歴を一括で共通領域へ移すことはありません。共通利用を有効にして新しく質問した回答から蓄積します。APIでは `shareAnswer: true` を明示し、意味照合には追加で `semanticReuse: true` が必要です。更新した画面は共有チェックに連動して両方を送ります。旧クライアントなどで後者が省略された場合、質問文を意味照合用に保存しません。基準となる回答の索引作成は応答後に行うため、登録直後は言い換えで見つからない場合があります。個人履歴内の完全一致による再利用も残し、同じブラウザ・条件・処理の版が一致する7日以内の回答が対象です。

直近200件の自分の質問と分野・表現・数値を比較し、質問文、数値・単位、利用日、会社、会話の前提の変更を表示します。条件が違う場合は通常のAI処理で確認します。別の利用者の個人履歴を一覧・比較対象にしません。共通回答にヒットした場合も、元の利用者の私的な比較メモは表示しません。

最終回答を再利用できなくても、BGE検索用ベクトルとGemmaの条文選択は、それぞれの入力が完全一致する場合にサーバーで再利用します。条文選択の再利用には候補原文・履歴・モデル・処理の版も含めて照合します。この検索処理用キャッシュはハッシュ・ベクトル・候補IDを保持し、質問文や利用者のCookieを保存しません。意味照合用の共有質問テーブルとは別です。質問の検索ベクトルは意味照合と通常検索で使い回し、同じ要求での二重生成を避けます。

ビルドで資料・検索インデックス・サーバーとライブラリのソースから版のハッシュを生成します。資料・プロンプト・モデル設定・検証処理を更新すると古い回答と条文選択は再利用されません。過去の履歴自体は残ります。

## 回答と表示

1. BGE-M3の意味検索と語句検索を組み合わせて関連条文を集めます。
2. Gemma 4が質問に直接必要な資料を選びます。「第○条だけ」と指定した場合はその資料に限定します。
3. Qwen 3.8 27Bが券種・適用除外・数値・会話条件を照合します。0.13以降と同じ推論設定・入力・生成予算を維持しています。
4. 出典IDを検証し、そのIDに対応する収録原文をサーバーが復元します。原文をAIに書き写させません。

途中の検索・条文選択・回答生成状況を表示します。回答の完了時に一番下へ自動スクロールせず、送信した質問を表示した位置を保ちます。読み進める際は利用者がスクロールします。

通常列車の自由席で、大人の人数と1〜5歳の同一年齢の幼児の人数が明示された単純な運賃人数質問には、第73条の原文と照合した計算も使います。例えば大人1人・4歳児3人は小児運賃1人分、大人3人・4歳児1人は0人分です。付き添いが有効な乗車券を所持する非団体の旅行を前提として明示し、指定席・団体・別年齢・追加条件などは通常のAIへ戻します。資料の版が変わるとこの計算案内も無効になります。

既存の確認済み基本案内と原文表示も維持します。基本案内に追加条件・会話前提がある場合はAI側へ戻します。初めての質問や条件を変えた質問はAIの推論が必要で、混雑・タイムアウトもあるため、すべての質問を数秒で返す保証はありません。モデルの小型化、推論の無効化、生成上限の削減はしていません。会話から自動で追加学習しません。

## 開発・公開

Node.js 22.13以降で `npm ci`、`npm run typecheck`、`npm run build` を実行します。ビルドはAIを呼び出しません。`FREE_PLAN_CONFIRMED` の既定値は `0` です。

D1データベースを用意し、`wrangler.jsonc` の `DB` バインディングのIDを設定します。初期化は `wrangler d1 migrations apply ryoki-navi-history --remote` で行います。既存の本番DBにはテーブルと索引を作成済みです。共通回答は `0003_shared_answers.sql`、意味照合用の質問・別名は `0004_semantic_cache.sql`、範囲検索の索引は `0005_scope_index.sql` にあります。0.16のテーブル・索引は本番とローカル確認用DBに適用済みです。ローカル確認は `wrangler d1 migrations apply ryoki-navi-history --local --config wrangler.preview.jsonc` と `wrangler dev --config wrangler.preview.jsonc` を使います。

運用者がWorkers Freeを確認したうえで `wrangler deploy --var FREE_PLAN_CONFIRMED:1` により公開します。認証情報・利用者Cookie・履歴DB・ローカルの `.wrangler` データを公開ソースへ含めないでください。

資料更新時は `scripts/build-semantic-index.mjs` で検索インデックスを再生成し、通常ビルドで資料との対応を確認します。自前サーバーへ移す際はAI呼び出しとD1をそれぞれ推論サーバーとSQLite等に置き換えます。
