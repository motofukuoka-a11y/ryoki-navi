# 旅規ナビ 0.11 — サーバーAI試用版

公開URL: https://ryoki-navi-trial.motofukuoka-ryoki.workers.dev/

従来の入口 https://motofukuoka-a11y.github.io/ryoki-navi/ からも試用版へ移動します。

Cloudflare Workers FreeとWorkers AIの無料枠を使い、Gemma 4で出典付きの参考回答を作成します。利用者のログインは不要です。端末へAIモデルをダウンロードさせず、サーバーで検索・生成します。Enterは改行、送信ボタンで送信します。

個別条件を含む質問はAIへ渡し、一般的なFAQと第190条の券面図については原文に照合した基本案内を優先します。AI回答は草案と照合の2段階で生成し、出典IDを検証します。意味の正確性を保証するものではなく、出典の原文も確認してください。

## 無料枠

Workers Freeの現在のプランを管理画面で確認して公開しています。有料プランへの変更やクレジット購入は行いません。CloudflareのAI無料枠は1日10,000 Neuronsで、日本時間9時にリセットされます。上限に達するとAI呼び出しは失敗し、アプリは関連する原文を表示します。有料の別サービスへの自動切り替えや再試行はありません。アプリ独自の「1日20回答」という制限は設けません。実際の利用可能量は提供元の条件と、同じアカウント内の他の利用にも左右されます。

公式条件: https://developers.cloudflare.com/workers-ai/platform/pricing/

## 資料とデータ

2026年11月19日確認のJR北海道の公開資料35件・760区分を収録しています。省略と未統合の改正があり、JR東日本・ICカード・企画乗車券の専用規則は未収録です。

質問・会話の一部・検索した公開資料をCloudflareで処理します。アプリはサーバーに質問・回答・利用件数を保存しません。画面の会話はメモリ内だけで、再読み込みすると消えます。旧版の個人データや訂正メモには接続しません。追加学習は行わず、内容を確認して改修します。
