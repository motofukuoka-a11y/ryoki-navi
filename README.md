# 旅規ナビ 0.13 — 確認済み案内・原文表示の高速化

公開: https://ryoki-navi-trial.motofukuoka-ryoki.workers.dev/

JR北海道の公開資料を検索し、出典を付けて回答するWebアプリです。利用者のログイン、端末へのAIモデル保存、WebGPUは不要です。Enterは改行、送信ボタンで送信します。

## すぐ返せる回答と履歴

新しいチャットで、収録原文に照合した定型質問に一致する場合は、組込みの基本案内を表示します。途中下車・未使用普通乗車券の払いもどし・有効期間・小動物の一般的な条件と、定期券の誤乗無賃送還に関する確認済み案内が対象です。質問の追加条件や会話の文脈がある場合は、この案内へ短絡しません。資料を更新すると案内は無効になり、再照合するまでAI側へ戻ります。

「第291条の原文を見せてください」等の原文表示もAI生成を待ちません。長い条文の収録部分もすべて表示します。省略箇所を現行全文として補完する機能ではありません。

個別の判断には0.12と同じQwenモデル、推論設定、入力、出典検証を使用します。すべてのAI質問の高速化を保証するものではなく、混雑やタイムアウトは発生し得ます。

履歴の永続保存はありません。会話はページ内メモリで保持し、再読み込み・タブを閉じると消えます。「ファイルに保存」は、利用者が選んだ場合だけ現在の回答と出典を書き出します。組込み案内は公開規則から作成した文章で、訪問者の会話履歴をキャッシュしているわけではありません。

## AI回答の仕組み

1. BGE-M3の意味検索と語句検索を組み合わせて関連条文を集めます。公式本文403区分の検索用ベクトルをサーバーの公開データとして同梱しています。モデルの学習や追加学習ではありません。
2. Gemma 4が質問に直接必要な資料を選びます。条文を指定して「だけ」と依頼した場合は、その資料に限定します。長い条文の後続部分も検索対象です。
3. Qwen 3.8 27Bの推論モデルが、券種・適用除外・数値条件・会話の追加条件を読んで回答します。精度を優先するため、回答に1〜2分程度、場合によってはそれ以上かかります。
4. 回答の参照IDを検証し、そのIDに対応する原文をサーバーが復元して表示します。原文をAIに書き写させません。原文と一致する参照があっても、結論の正確性を保証するものではありません。

入力・生成が失敗した場合は、AI回答として提示せず関連原文を表示します。再試行や有料AIへの自動切替は行いません。

## 費用・データ

現在確認済みのCloudflare Workers Freeで運用します。AI無料枠は1日10,000 Neuronsで、日本時間9時にリセットされます。上限に達するとAI呼び出しは失敗します。有料プランへの変更やクレジット購入はしていません。アプリ独自の回数制限は設けません。

公式条件: https://developers.cloudflare.com/workers-ai/platform/pricing/

2026年11月19日確認のJR北海道の公開資料35件・760区分を収録しています。本文には省略と未統合の改正があります。JR東日本・ICカード・企画乗車券の専用規則は未収録です。

質問・会話の一部・関連する公開資料をCloudflareで処理します。アプリはサーバーに質問・回答・利用件数を保存しません。会話はページ内のメモリだけで保持し、再読み込みで消えます。必要な回答は「保存」から書き出せます。会話から自動学習しません。

## 開発・公開

Node.js 22.13以降を使用し、`npm ci`、`npm run typecheck`、`npm run build`を実行します。`npm run dev:server`でローカル確認できます。無料プラン確認前のAI呼び出しを防ぐため、`FREE_PLAN_CONFIRMED`の既定値は`0`です。

運用者が公式Wranglerで接続し、Workers Freeを確認したうえで、`wrangler deploy --var FREE_PLAN_CONFIRMED:1`により既存Workerを更新します。認証情報をソースやブラウザーのコードに入れないでください。

資料を更新したときは、許可した環境変数を使って`node scripts/build-semantic-index.mjs`で検索用インデックスを再生成します。認証情報は出力・保存しません。通常のビルドはAIを呼び出さず、資料とインデックスの対応・完全性を検証します。

将来自宅サーバーへ移す場合は、`server/handler.ts`の推論呼び出しと意味検索用モデルを、自前の推論サーバーへ置き換えます。
