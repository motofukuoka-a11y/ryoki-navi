# 旅規ナビ

公開された旅客営業規則を、公式資料と出典から調べるブラウザAIアプリです。

## 利用方法

アカウント登録・ログインはありません。基本案内・資料検索はそのまま使えます。会話AIは「ブラウザAIを準備」ボタンから起動します。初回のモデル取得は約2.4GBで、WebGPU対応のブラウザが必要です。

AIはQwen3.5 4Bの4bit量子化版を、利用中の端末で実行します。質問を外部の生成AI APIに送りません。資料検索もブラウザ内で行い、回答には出典を表示します。

Enterは改行です。送信ボタンを押すと送信します。会話はページ内のメモリだけに保持し、再読み込みで消えます。必要な回答は「保存」から書き出せます。モデルのファイルはブラウザにキャッシュします。

## 収録範囲

2026年11月19日に確認したJR北海道の公開資料35件を収録しています。公開資料には省略と未統合の改正があります。JR東日本、ICカード、企画乗車券の専用規則は未収録です。非公式の調査支援として利用し、個別の取扱いは原文と照合してください。モデルの追加学習を行う機能は含まれていません。

## 開発と公開

`source-*.zip`は編集可能なソース、`site-*.zip`はビルド済みの公開ファイルを分けたものです。それぞれ全てを同じフォルダーに展開してください。いずれにも個人の会話履歴・訂正メモ・認証情報は含みません。

ソースを展開し、Node.js 22.13以上で `npm ci`、`npm run typecheck`、`npm run build` を実行します。`dist/`の内容を分けた`site-*.zip`とSHA-256一覧の`site.sha256`を更新すると、GitHub Pagesの公開処理が動きます。公開ファイルは相対URLで構成しており、一般的な静的ホスティングへ配置できます。

サーバーアプリ・データベース・生成AI APIキーは不要です。モデルの配布元はHugging Face / MLC AIです。モデルや各ライブラリのライセンスはそれぞれの配布元に従います。公式規則PDFの発行元・掲載先は`public/documents/source_inventory.json`から確認できます。
